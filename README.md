# agakadula

A minimal English website for Agnieszka Kadula, personal training in Zurich.

Contact: [@agnieszka.kadula](https://www.instagram.com/agnieszka.kadula/).

## Website

Once GitHub Pages is enabled: https://akadula93-svg.github.io/agakadula/

## Publishing

In Settings → Pages, select **Deploy from a branch**, choose **main** and **/(root)**, then save. Future changes to `index.html` on `main` will publish automatically.

No installation or build step is needed.
